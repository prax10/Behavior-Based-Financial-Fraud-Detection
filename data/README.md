# Data

Datasets are not included in this repository because of their size.

| File | Description |
|---|---|
| `Processed_data_FD.csv` | Preprocessed e-commerce transaction data (~1.5M rows, ~215 MB). Normalized numeric features, one-hot encoded product category, payment method and device, plus `Same ship and bill` and `Location_Freq`. Target: `Fraudulent Transaction (Yes/No)`. |
| `optimal_10k_dataset.csv` | 10,000-row representative sample (3,000 fraud / 7,000 non-fraud), generated by `build_optimal_10k_dataset.py`. Used by all modelling scripts. |

Place both files in this folder before running the scripts.
